# Notes App

Веб-приложение для создания и организации заметок. Проект задумывался как удобный сервис, где можно быстро записать мысли, оформить текст, разложить заметки по цветам и папкам.

Фронтенд написан на React 19 и Vite, бэкенд — на NestJS и Prisma с базой данных PostgreSQL.

## Что сделано в проекте

- **JWT-авторизация с ротацией токенов:** в проекте используется связка access и refresh токенов. Access токен хранится в памяти приложения, а refresh токен лежит в защищенных httpOnly cookie. На клиенте настроены интерцепторы Axios: если срок действия access токена заканчивается, клиент сам делает запрос за новым токеном и продолжает работу без разлогина пользователя.
- **Подтверждение почты и сброс пароля:** при регистрации и восстановлении пароля на указанный email приходит письмо с 6-значным кодом подтверждения. У кодов есть ограничение по времени действия и количеству попыток ввода.
- **Кодогенерация API на клиенте:** все типы и функции для запросов к серверу генерируются автоматически по спецификации OpenAPI из Swagger с помощью библиотеки `swagger-typescript-api`. По умолчанию все типы уже сгенерированы и лежат в папке `web/src/api/generated`, поэтому запускать кодогенерацию перед первым стартом не нужно.
- **Удобный текстовый редактор:** форматирование текста, заголовки и списки работают на базе редактора TipTap. Для защиты от XSS весь HTML очищается библиотекой DOMPurify.
- **Управление заметками:** для каждой заметки можно выбрать один из 12 цветов, а также переместить ее в архив или корзину. Из корзины заметку можно восстановить или удалить навсегда. Есть поиск по названию и тексту.
- **Темы и языки:** в настройках можно переключить светлую или темную тему, а также выбрать русский или английский язык. Выбранные параметры сохраняются в базе данных в профиле пользователя.
- **Адаптивный интерфейс:** верстка написана на SCSS и адаптирована под экраны телефонов и планшетов.

## Стек технологий

**Frontend:**
- React 19, TypeScript, Vite
- TanStack Query v5 — серверное состояние и кеширование данных
- Zustand — клиентское состояние
- TipTap — редактор текста
- React Hook Form и Zod — формы и валидация
- SCSS — стили и адаптивность
- Axios — HTTP-запросы
- swagger-typescript-api — генерация API-клиента

**Backend:**
- NestJS 11, TypeScript
- Prisma ORM 7 с драйвером pg
- PostgreSQL 18
- JWT, bcryptjs, cookie-parser
- Nodemailer — отправка писем на почту
- Swagger — документация API

**Инструменты:**
- pnpm — пакетный менеджер
- Docker Compose — быстрый запуск базы данных

## Быстрый запуск

### Требования
- Node.js (версия 20 или выше)
- pnpm (`npm install -g pnpm`)
- Docker и Docker Compose

---

### 1. Клонирование репозитория

```bash
git clone https://github.com/StepanNv/notes-app.git
cd notes-app
```

---

### 2. Запуск базы данных

В папке `server` лежит файл `docker-compose.yml` для запуска PostgreSQL:

```bash
cd server
docker compose up -d
```

База данных запустится на порту `5433`.

---

### 3. Запуск сервера

1. Перейдите в папку `server` и установите зависимости:
   ```bash
   cd server
   pnpm install
   ```

2. Создайте файл `.env`:
   ```bash
   cp .env-example .env
   ```
   *(в Windows PowerShell: `Copy-Item .env-example .env`)*

3. Примените миграции и сгенерируйте клиент Prisma:
   ```bash
   pnpm exec prisma migrate dev
   pnpm exec prisma generate
   ```

4. Запустите сервер:
   ```bash
   pnpm run start:dev
   ```

Сервер запустится на `http://localhost:3000`.

---

### 4. Запуск клиента

1. В новом окне терминала перейдите в папку `web`:
   ```bash
   cd web
   ```

2. Установите зависимости:
   ```bash
   pnpm install
   ```

3. Запустите клиент:
   ```bash
   pnpm run dev
   ```

Приложение откроется по адресу `http://localhost:5173`.

---

## Кодогенерация API (swagger-typescript-api)

Все типы и клиентские запросы уже сгенерированы и находятся в папке `web/src/api/generated`. Проект сразу готов к работе после установки зависимостей.

Если вы изменили контроллеры или DTO на бэкенде и хотите обновить типы на клиенте:

1. Запустите бэкенд, чтобы была доступна схема по адресу `http://localhost:3000/api-json`.
2. В папке `web` выполните команду:
   ```bash
   pnpm run codegen:api
   ```
Скрипт сам скачает свежую схему из Swagger и обновит файлы в `src/api/generated`.

## Swagger документация

Когда бэкенд запущен, доступна интерактивная документация API:

**http://localhost:3000/api**

Здесь можно посмотреть доступные ручки и протестировать запросы прямо из браузера.

## Переменные окружения

Настройки сервера задаются в файле `server/.env`:

| Переменная | Описание | Пример |
|---|---|---|
| `PORT` | Порт сервера | `3000` |
| `ACCESS_JWT_SECRET` | Секрет для access токена | `access_jwt_secret` |
| `REFRESH_JWT_SECRET` | Секрет для refresh токена | `refresh_jwt_secret` |
| `ACCESS_JWT_EXPIRES` | Время жизни access токена в секундах | `900` |
| `REFRESH_JWT_EXPIRES` | Время жизни refresh токена в секундах | `604800` |
| `POSTGRES_HOST` | Хост базы данных | `localhost` |
| `POSTGRES_PORT` | Порт базы данных | `5433` |
| `POSTGRES_DB` | Имя базы данных | `notes_app` |
| `POSTGRES_USER` | Пользователь базы данных | `postgres` |
| `POSTGRES_PASSWORD` | Пароль к базе данных | `postgres` |
| `POSTGRES_URL` | Строка подключения для Prisma | `postgresql://postgres:postgres@localhost:5433/notes_app` |
| `MAIL_HOST` | SMTP хост для отправки писем | `smtp.example.com` |
| `MAIL_PORT` | Порт SMTP | `465` |
| `MAIN_LOGIN` | Логин или email почты | `support@example.com` |
| `MAIN_PASSWORD` | Пароль от почты | `your_password` |
